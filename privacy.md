# IconAnchor Privacy Policy

Last updated: October 19, 2026

IconAnchor is developed by Peter Verhoeven.

## Information used by the app

IconAnchor reads desktop item names and paths, icon positions,
and monitor configuration information to remember and restore
desktop icon arrangements. Paths may include your Windows
username or personally identifying file names.

The app observes mouse button actions and pointer positions
to detect deliberate desktop icon moves. It does not record
keystrokes or read the contents of your documents.

## Local storage

Desktop layout information is saved on your computer.
The Microsoft Store version saves layouts in its per-user
application data folder. The standalone version saves layouts
in the Data folder beside IconAnchor.exe.

IconAnchor does not send layout information to the developer
or other parties. It includes no advertising, analytics,
or tracking services.

## Your controls and deleting layouts

You can pause icon positioning or exit IconAnchor using its
system tray menu. You can also enable or disable startup
with Windows.

For the Microsoft Store version:
1. Right-click the IconAnchor system tray icon.
2. Select Open layout folder.
3. Right-click the tray icon again and select Exit.
4. Delete layouts.dat from the folder you opened.

For the standalone version, exit IconAnchor and delete the
Data folder beside IconAnchor.exe.

Deleting saved layouts removes remembered arrangements.
If you launch IconAnchor again, it will learn new layouts.

## Microsoft Store and website services

Microsoft processes Store purchases and may collect information
under its own privacy policy:
https://privacy.microsoft.com/privacystatement

This privacy-policy webpage and the support issue tracker
are hosted by GitHub. GitHub may process visitor and account
information under its privacy statement:
https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

Opening privacy or support links uses your web browser.
Those services operate separately from IconAnchor's local
layout tracking.

## Contact and support

For questions or support, visit:
https://github.com/PeterVerhoevenUSA/iconanchor/issues

GitHub issues are public. Do not post tax IDs, passwords,
private file paths, or other sensitive information.

If you submit a support issue, the information you choose
to include will be visible to the developer and other visitors.
